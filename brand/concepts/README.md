# Alternative directions

Three other ways to draw the same brief — the same palette and the same
Cormorant Garamond wordmark, but a different idea behind the symbol each time.
None of these is finished artwork: each is a direction to choose from, and the
chosen one gets the full treatment (compact, stacked, mark, badge, favicon,
one-colour, PNG exports) that `../assets` has today.

| Concept | Idea |
| --- | --- |
| `c1-leaf-face` | One leaf, read two ways: its inner edge is a face in profile. Beauty as something that grows. |
| `c2-seal` | An editorial seal — profile inside a double hairline ring, closed by a laurel. Magazine authority, works well as an avatar. |
| `c3-type-led` | No separate symbol: the descender of the "y" keeps growing, sweeps under the wordmark and rises at the left to become the head. |

Regenerate with `python3 src/concepts.py concepts` (needs the fonts fetched by
`generate.py`, plus playwright for `c3`, which sizes its canvas by measuring its
own ink).
